
The main issue I had when I was designing the code for this was having efficiency with structure. I wanted to make sure I had the output come out as correct but I needed it to not be slow for practical use. What I did was I made a set for tracking if an element has already been seen. This allows it to be checked quickly for spotting if the element appeared more than once in the set. Then it makes it into a list to preserve the order it was in. It appends the list that is made so the output would be the same as the set you put in at first. I could have used a dictionary as it does preserve the order, but it is less explicit in showing the separation between what is unique in a set and what is ordered like in a list. The combination of a set and a list provides the best balance of clarity, efficiency and structure that ensures that this code can detect duplicates in a timely manner that is fast and guarantees that the original order of the set can be preserved.  With this I was able to complete the task within the time limit provided
